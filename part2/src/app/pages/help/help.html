User Guide & Frequently Asked Questions

How to add an inventory item?

Go to the Inventory page, enter a valid item name and quantity (≥ 1), then click the Add Item button.

How to delete an item?

Click the red Delete button next to any item to remove it from your inventory list.

How does the search function work?

Type any keyword in the Search page. The system will automatically filter and show matching items in real time.

Is my data secure?

All data is stored locally in your browser. No personal information is collected or shared with third parties.

Is this application responsive?

Yes! The interface automatically adjusts to mobile phones, tablets, and desktop screens.
